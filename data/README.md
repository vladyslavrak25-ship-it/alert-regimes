# Джерело даних

`volunteer_data_en.csv` — знімок, який користувач надав для аналізу 10 жовтня 2026 року.

Джерело: https://github.com/Vadimkin/ukrainian-air-raid-sirens-dataset

Це волонтерська реконструкція повідомлень, не гарантований повний журнал усіх сигналів. `naive=True` позначає умовні часи завершення.

**Важливо:** час останньої події в CSV не дорівнює часу публікації або оновлення файлу. Для фінального проєкту потрібно зафіксувати версію знімка та перевірити свіжість.
